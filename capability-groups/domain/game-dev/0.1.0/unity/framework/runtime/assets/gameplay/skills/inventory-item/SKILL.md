# 背包与物品

## 工作流

1. **物品定义**：配置表里定义 id、类型、最大堆叠、图标、描述 key。
2. **容器**：角色/仓库各建 `Container`，启动时按初始物品填充。
3. **加入**：`TryAddItem(item)`；返回失败要区分"满"与"无效"。
4. **堆叠**：框架不读 `MaxStack`，加之前自己算已堆数量。
5. **移除**：移除后发事件，事件里自己带物品 id（框架事件里恒为 0）。
6. **装备**：`Equip` 穿戴；装备属性加成需自行接入战斗属性集。
7. **UI**：订阅容器事件刷新格子，不轮询。

## 约束

- 容器只存运行时实例，不直接引用配置表对象。
- 物品数量变化统一走容器方法，不直接改字段。
- 存档只存 `id + count + 槽位状态`。
- 装备/卸下要成对处理属性加成（当前装备 Buff 未实现，需自己写）。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 堆叠无限 | 没校验 `MaxStack` | 加入前判断 |
| 装备不加属性 | 装备 Buff 未实现 | 手动应用属性修正 |
| 移除后 UI 不刷新 | 没订阅事件或事件缺 id | 发自定义事件带 id |
| 读档后物品错位 | 存档字段与容器结构不一致 | 存档只存稳定字段 |
