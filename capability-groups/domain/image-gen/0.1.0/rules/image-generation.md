# 图像生成规则

适用于所有“文字描述生成图片”的任务，包括游戏概念图、角色/道具参考图、宣传图和迭代草图。

## 免费边界

- 本组只使用 Pollinations 的匿名图像 URL 端点：`https://image.pollinations.ai/prompt/{prompt}`。该端点不需要 API key，不扣账户余额，按请求直接返回图片字节。
- 不调用任何需要 API key、账户余额或订阅的图像接口；不把“升级账户/充值/换模型”作为失败后的建议。
- 如果端点返回 401/402/403，说明免费通道暂时不可用：停止，向用户报告状态码与原始信息，不改用其他通道。
- 匿名端点有速率与共享缓存限制；连续生成之间留出间隔，不并发轰炸。

## 结果契约

- HTTP 响应体不是交付物。每张图必须下载到项目内 `assets/images/<slug>/`，并校验文件类型、大小和可解码性。
- 每张图保存同名 sidecar JSON：`prompt`、`model`、`seed`、`width`、`height`、`source_url`、`downloaded_at`、`sha256`、`bytes`。
- 文件名使用 `<slug>-<seed|yyyyMMdd-HHmmss>.jpg`（或按实际 Content-Type 用 `.png`/`.webp`）；不覆盖已有文件，重跑用新文件名。
- 交付时给出本地路径、尺寸、提示词和 seed；不要把临时 URL 当成长期资产。

## 质量检查

- 检查主体是否正确、构图是否完整、有无文字/水印伪影、手部与边缘是否异常、风格是否符合 brief。
- 不合格时先修改提示词或参数，再生成下一张；不要用完全相同的 URL 重复请求，除非就是要取缓存结果。
- 需要透明背景、精确文字、多图严格一致性时，明确说明当前免费端点不保证，需后期处理或换工具。

## 内容边界

- 不生成违法、仇恨、骚扰、性剥削内容，不生成侵犯真人肖像权或商标的内容。
- 可以描述流派、年代、材质和视觉语言，但不冒用在世艺术家的独特风格或要求“完全像某位艺术家”。
- 不承诺接口没有的能力，例如透明通道、指定字体排版、角色多视图严格一致。
