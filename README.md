# HNFlow — AI 工作流编排与执行系统

HNFlow 是一套**领域无关的本地桌面端工作流编排与执行系统**，面向软件开发者和 AI 工作流构建者，定位为 AI 时代的「流程管家」。它将 AI 生成、人工操作、专业软件执行串成可复用、可嵌套的自动化流程。

## 功能定位

- **可视化拖拽编辑**：基于 AntV X6 图引擎，支持节点拖拽、连线配置、参数编辑，直观构建复杂工作流
- **AI Agent 对话辅助**：通过自然语言生成工作流、调度执行、监控进度、排查异常，双入口平权自由切换
- **MCP 原生集成**：以 MCP 协议为首选工具连接方式，可接入 Unity、Blender、Git、命令行等外部工具
- **功能组（Capability Group）体系**：按领域以命名空间方式组织 AI 能力，支持语义版本、依赖管理、懒加载，将软件工程的包管理思想平移到 AI 能力管理

## 特色能力

- **三级节点体系**：原子节点（内置）→ 子工作流节点（复合）→ LLM 原子节点（AI Agent），覆盖从简单到复杂的全部场景
- **人机协同一等公民**：人工节点拥有完整生命周期（任务描述、产物校验、打回重交、兜底策略），AI 中断与人工任务统一管理
- **无限层级嵌套**：子工作流支持无限嵌套，循环依赖全链路检测，常用流程可保存为模板
- **断点续跑**：每步执行持久化，程序崩溃后重启可从断点恢复
- **能力按需加载**：功能组只在执行到对应节点时懒加载，缓存复用，不浪费资源
- **版本不可变**：功能组和子工作流模板采用语义版本管理，每个版本只读快照，引用锁定固定版本
- **六层架构**：用户交互层 → 工作流图模型层 → 编排层 → 执行引擎层 → 基础设施层 → 工具适配层，单向依赖，职责清晰

## 技术栈

| 维度 | 选型 |
|------|------|
| 语言 | TypeScript |
| 运行时 | Node.js / Electron |
| 图引擎 | AntV X6 |
| AI 运行时 | LangGraph.js |
| AI 协议 | MCP（Model Context Protocol） |
| 存储 | SQLite + JSON 文件 |

## 开发路线

- **v0.1.x** — 核心引擎骨架（图模型、执行引擎、原子节点、断点续跑）
- **v0.2.x** — AI 节点运行时（LangGraph 集成、统一挂起、并行/循环/异常处理）
- **v0.3.x** — 功能组体系（存储、依赖解析、运行时加载、版本管理）
- **v0.4.x** — 可视化编辑器（X6 编辑器、版本交互、AI Agent 对话）
- **v1.0.x** — 桌面端体验与生态（托盘驻留、异常恢复、功能组生态）
